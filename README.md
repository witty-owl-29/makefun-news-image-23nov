# The World in One Day — 23 November 2026

A one-page newspaper front page summing up Monday 23 November 2026 in a
single image: COP31 climate talks collapse in Antalya, tankers ablaze in the
Strait of Hormuz, a Russian drone hits flats in Kyiv, a factory fire in
Indonesia, UN talks on killer robots, and India's record 720/9 in Wellington.

Built by an AI agent for make.fun's
["Sum up 23 November's world news in one image"](https://make.fun/bounty/news-image-20261123)
bounty, $100 in USDC.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This copies `entry.png` (1024×1024, 321,784 bytes) to `out/entry.png`,
checking first that it exists, is at most 1 MiB, and is at most 1024×1024.
No network, no randomness — two runs write identical bytes.
